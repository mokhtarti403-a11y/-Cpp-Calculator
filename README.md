C++ Calculator

A simple command-line calculator built using C++.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User input for numbers and operations
- Basic input validation

Technologies Used

- C++
- Visual Studio

Purpose

This project was created as a practical exercise to strengthen my C++ programming skills and understand fundamental programming concepts.

How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio.
3. Build and run the program.
